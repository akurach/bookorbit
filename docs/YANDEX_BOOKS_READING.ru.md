# Импорт чтения из Яндекс Книг

[English documentation](YANDEX_BOOKS_READING.md)

Интеграция переносит книги, статусы и прогресс из личной библиотеки Яндекса в
BookOrbit. Работает внутри существующего сервера и его базы. Дополнительный сервис
на Raspberry Pi или приложение на читалке не нужны. Публичный поиск метаданных
Яндекса настраивается отдельно и не требует аккаунта.

## Подключение

1. Задать на сервере `YANDEX_BOOKS_ENCRYPTION_KEY`: ключ из 64 шестнадцатеричных
   символов, созданный командой `openssl rand -hex 32`. Перезапустить сервер.
   Ключ шифрует токен в базе; сохранить его для восстановления.
2. Пользователю нужны разрешения **Yandex Books import**, **Upload books** и право
   редактировать библиотеку. У администратора они уже есть.
3. Открыть **Settings > Accounts > Yandex Books**, ввести токен доступа,
   выбрать библиотеку и папку будущих файлов. Сохранить подключение и проверить
   имя аккаунта, полученное от Яндекса.
4. Запустить предпросмотр, проверить список и выполнить импорт.
5. Включить обновление по расписанию и выбрать интервал. Результат последнего
   обновления, следующая проверка и ошибки отображаются там же.

После сохранения токен не показывается. Если он отозван или истёк, нужно
подключиться заново. Отключение удаляет учётные данные и останавливает обновления,
сохраняя импортированные книги. Используйте HTTPS или доверенную локальную сеть.

Карточки и метаданные видны участникам выбранной библиотеки по её обычным правилам.
Подключение, статусы и прогресс принадлежат вашему пользователю BookOrbit.
Токены и личные ответы API нельзя публиковать в отчётах об ошибках.

## Статусы и прогресс

Текст, аудио и комиксы получают отдельные карточки. Файл для создания карточки
не нужен. Повторный импорт обновляет те же записи. Пропажа книги из ответа
Яндекса не удаляет её из BookOrbit.

Статус и процент сохраняются отдельно. В Яндексе встречаются прочитанные книги
с 0% и отложенные с 45%; статус «прочитано» нельзя вычислять только из процента.
Для аудио процент определяется по позиции и длительности. Это не количество
часов прослушивания. Единицы прогресса комиксов пока не подтверждены, поэтому
процент остаётся неизвестным.

Если после импорта изменить статус в BookOrbit, несовпадающее обновление из
Яндекса потребует выбора: сохранить локальное значение или принять Яндекс.
Неполная загрузка или ошибка сети не заменяет последний полный снимок библиотеки.

## Файл можно добавить позже

Открыть импортированную книгу и воспользоваться добавлением файла. Подойдут EPUB,
FB2 и другие форматы BookOrbit. Сохранится та же карточка с идентификатором и
сведениями Яндекса. Пустые карточки не удаляются при сканировании файловой системы.

Процент Яндекса остаётся отдельным показателем. Он не заменяет позицию локального
чтеца, данные KOReader, заметки или сессии. У другого издания или перевода одинаковый
процент не обязательно означает ту же страницу.

Цитаты оставлены на следующий этап. Скачивание файлов по подписке, отправка
изменений обратно в Яндекс и восстановление недоступной истории сессий не входят
в эту версию.

## Обслуживание

Расписание работает, пока включён сервер. Блокировка в базе защищает от
одновременных запусков и имеет срок действия для восстановления после сбоя.
При ошибке прежние данные сохраняются. Резервная копия должна включать базу,
файлы и ключ шифрования.

Используемый API аккаунта не является официальным публичным контрактом Яндекс
Книг и может измениться.
